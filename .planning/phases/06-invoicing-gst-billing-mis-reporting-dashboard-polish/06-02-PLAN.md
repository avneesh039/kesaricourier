<task type="auto">
  <name>Task 1: Build GstService for Indian GST Logistics Tax Calculations</name>
  <files>src/Services/GstService.php</files>
  <action>
    Create src/Services/GstService.php:
    1. Determine whether transaction is Intra-State or Inter-State:
       - Compare Agency Tenant GST State Code (first 2 digits of GSTIN or state) with Client GST State Code.
       - Intra-State (e.g. Chhattisgarh 22 to 22) -> CGST (9%) + SGST (9%) = 18%.
       - Inter-State (e.g. Chhattisgarh 22 to Maharashtra 27) -> IGST (18%).
    2. Compute Fuel Surcharge (e.g. 10% on freight subtotal).
    3. Add Docket Fees (e.g. Rs 50 or custom).
    4. Taxable Value = Subtotal + Fuel Surcharge + Docket Charges.
    5. Calculate GST amounts and Round-Off.
    6. Number-to-Words Indian currency converter (e.g., "Rupees Five Thousand Four Hundred Only").
  </action>
  <verify>
    & "C:\xampp\php\php.exe" -l src/Services/GstService.php
  </verify>
  <acceptance_criteria>
    - GstService correctly splits CGST/SGST vs IGST
    - Computes fuel surcharge and converts total to Indian currency words
  </acceptance_criteria>
  <done>GST service functional</done>
</task>
